AquaLink

{% if lang == 'en' %}

A personal file browser that connects a PowerPC Mac G4 running Mac OS X Tiger to modern SMB3 file shares, or exposes the G4 itself as a NAS-like storage target from current Macs. It allows Tiger's standard Finder to access modern SMB3 shares via WebDAV-mounted volumes as if they were normal disks.

View Source on GitHub
A prebuilt app bundle for easier installation is in preparation and will be published here soon.

Main Features

  • Connect using smb3:// URLs and passwords (NTLMSSP authentication)
  • Directory listing without garbled Japanese filenames
  • Connect to Finder via /Volumes mount and show as desktop icons
  • Direct drag-and-drop copying from Finder
  • Reverse mode: expose the G4 itself as a multi-folder NAS for current Mac and Windows systems
  • Auto reconnect of shared folders on login using saved settings and keychain
